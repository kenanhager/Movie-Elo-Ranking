MOVIE ELO & DISTRIBUTION RANKING SYSTEM
Technical Documentation & Operational Manual
================================================================================

1. SYSTEM OVERVIEW

The Movie Elo & Distribution Ranking System is a lightweight, zero-dependency 
Python-based web application designed to evaluate, rank, and analyze film 
databases. The software integrates pairwise Elo rating algorithms, cluster 
ranking models, dynamic programming cutoffs, and standard normal distribution 
analytics with Letterboxd CSV data ingestion.

--------------------------------------------------------------------------------
2. SYSTEM SETUP & DEPLOYMENT PROCEDURE
--------------------------------------------------------------------------------

Prerequisites: Python 3.x environment.

Step 1: Dependency Installation
Execute the following command in your system terminal to install required external packages:

    pip install requests

Step 2: Server Initialization
Launch the application server by executing the main script:

    python main.py

Step 3: Web Interface Access
Access the web user interface via a standard web browser at:

    http://localhost:8000

3. DATA INGESTION & CSV SPECIFICATIONS
--------------------------------------------------------------------------------

The system supports database initialization and synchronization via CSV file uploads.

3.1 Supported File Schemas

* Letterboxd Export Schema ('ratings.csv'):
  Standard export file generated by Letterboxd user profiles.
  Required fields: 'Name' (Film Title), 'Year' (Release Year), 'Rating' (Numeric 0.5-5.0).

* Custom CSV Schema:
  Generic structured spreadsheets containing header keys corresponding to Title, 
  Year, Rating, or Elo.

3.2 Mathematical Transformation: Star Ratings to Elo Baselines

When static numerical ratings (0.5 to 5.0 stars) are imported, the system maps 
each entry to an initial Elo rating utilizing normal distribution parameters:

1. Sample Mean ($\mu$) and Standard Deviation ($\sigma$):
   The application computes the sample arithmetic mean ($\mu$) and standard 
   deviation ($\sigma$) across all valid numerical ratings in the imported file.

2. Standard Score ($z$-Score) Calculation:
   Each film's relative positional value is determined via:
   $$z = \frac{r - \mu}{\sigma}$$
   where $r$ represents the film's explicit rating.

3. Linear Elo Mapping:
   The computed $z$-score is linearly transformed to the target Elo scale:
   $$\text{Initial Elo} = \text{DEFAULT\_ELO\_MEAN} + (z \cdot \text{DEFAULT\_ELO\_STD})$$

   Default System Parameters (configurable in config.py):
   * $\text{DEFAULT\_ELO\_MEAN} = 1200.0$
   * $\text{DEFAULT\_ELO\_STD} = 200.0$

   Example: A 4.5-star rating within a dataset exhibiting $\mu = 3.2$ and $\sigma = 0.8$ 
   yields $z = 1.625$. The resulting mapped initial rating is $1200 + (1.625 \cdot 200) = 1525.0 \text{ Elo}$.

3.3 Import Execution Protocol

1. Navigate to the Data Management interface (/import).
2. Select the target file (e.g., 'ratings.csv').
3. Select the preferred operational mode:
   - Overwrite Mode: Purges the active database and initializes records from the file.
   - Merge Mode: Ingests new records and updates matching entries without truncating non-conflicting data.
4. Execute 'Upload and Process'.

3.4 Exception Handling & Data Integrity

* Unrated Entries: Records missing explicit ratings are assigned $\text{DEFAULT\_ELO\_MEAN}$ ($1200.0$).
* Homonymous Titles: Distinguishability between identical film titles is enforced via the release year parameter.
* Malformed Values: Non-numeric data in rating attributes are intercepted and bypassed safely.

--------------------------------------------------------------------------------
DATA EXPORT CAPABILITIES


Extracted data can be generated via the Data Management endpoint (/import) in the following formats:

* Primary Database File (save.csv): Contains Title, Year, Elo Score, Total Matches, and TMDB Identifier.
* Z-Score Normalized Output: Contains Title, Year, and continuous $z$-score metrics relative to dataset mean.
* Normalized Star Scale Output: Maps current Elo scores back to a 0.5-5.0 discrete scale using Preserved Count matching or Dynamic Programming cutoffs.
* Percentile Scale Output: Ranks items on a continuous 1.0-10.0 scale via the Gaussian cumulative distribution function $\Phi(z)$.

--------------------------------------------------------------------------------
RANKING & EVALUATION METHODOLOGIES


5.1 Pairwise Match Voting (/vote)
Executes direct head-to-head comparisons between two entities. Win, loss, or draw 
outcomes update the Elo ratings of both items according to standard Bradley-Terry / Elo formulas.

5.2 Rank 10 Cluster Sorting (/rank10)
Loads a localized cluster of 10 items possessing similar Elo scores. User ordering 
from rank 1 to 10 generates 45 implicit pairwise comparison outcomes, adjusting 
Elo ratings for all 10 records simultaneously.

5.3 Direct Rating Ingestion (/add)
Allows manual entry of a new item with a 1-10 score rating. The value is immediately 
converted into a $z$-score and mapped to an appropriate baseline Elo rating.

--------------------------------------------------------------------------------
STATISTICAL BINS & DISTRIBUTION ANALYTICS


The Analytics (/stats) and Bin View (/bin) modules partition the database into 10 
discrete statistical intervals ranging from Bin 1 ($z < -2.0\sigma$) to Bin 10 ($z \ge +2.0\sigma$).

Supported Partitioning Algorithms:
1. Standard Normal $z$-Score: Fixed boundaries based on standard normal deviation intervals.
2. Preserved Count Distribution (Method 1): Maintains the exact frequency distribution of the initial imported ratings.
3. Minimum Rating Deviation via Dynamic Programming (Method 2): Utilizes an $L_1$ norm minimization algorithm to establish optimal monotonic bin threshold cutoffs.

CONFIGURATION MATRIX (config.py)


Core application settings and visual attributes are defined centrally within config.py:

* HTTP Server Port: PORT = 8000
* Metadata API Key: TMDB_API_KEY
* Elo Distribution Baseline: DEFAULT_ELO_MEAN = 1200.0, DEFAULT_ELO_STD = 200.0
* System Styling: THEME_COLORS (HEX palette definitions) and UI_SIZES (layout dimensions).
